# RecoverAI

RecoverAI is an autonomous revenue recovery platform that detects revenue at
risk, diagnoses why it is at risk, recommends a recovery intervention using AI,
checks that intervention against merchant policies and guardrails, executes a
simulated recovery workflow, measures actual money recovered, and maintains a
complete audit trail.

## Tech stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- shadcn/ui
- Lucide React icons

Supabase and AI/LLM integration will be added later.

## Local development

Install dependencies (already done if you cloned a prepared project):

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Other useful commands:

```bash
npm run lint
npx tsc --noEmit
npm run build
```
